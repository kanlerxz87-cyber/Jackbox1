Private workflow

How the parcel location can be used to pick consistent census tracts and screen hazards on the owner's own machine, so no location reaches Git or this website.

4. Privacy design

  • Refuses to run unless private/ is git-ignored; refuses to write outside it.
  • Never prints coordinates; progress messages show counts only.
  • Public aggregates need at least ten tracts and carry no tract IDs.
  • Median values cannot be added across tracts. The aggregate reports the spread of tract medians and labels it as such; sums and ratios of counts are exact up to survey margins.
  • Compare vintages only when the tract IDs match; the script reports tracts missing from a vintage instead of guessing a crosswalk.
  • The API key comes from an environment variable and is never written to disk.

Residual risk: the optional online step discloses the location to a government server. Skip it if that matters; step 1 alone gives an approximate tract set.
