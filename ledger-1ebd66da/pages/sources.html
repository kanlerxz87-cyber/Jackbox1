Method notes

What "verified" means here

A value is verified when it was read directly from the official page during this session and the supporting text is quoted in the same row. That is a stronger standard than "a source exists" and a weaker one than "an auditor re-checked it". The quoted evidence is published so the second step can be done by anyone.

It is not a claim that the official figure is correct. Official series get revised. It is a claim that the figure shown is the figure published, on the date recorded.

What "derived" means here

A derived row is arithmetic on two or more verified observations — for example, the dollar change in median income between 2020 and 2024. The operation is stated, and every input observation is quoted, so the arithmetic can be checked.

No derived row is a forecast, a projection, or an extrapolation. Nothing on this site extends a series beyond its last published observation.

Build-time guarantees

A verification script runs before every deploy. It fails the build if any of the following is true, which means the site cannot be published in a state that violates these rules:

  • Any metric row cites a source key that does not exist in the register.
  • Any source URL is not HTTPS, or is not on the official-domain allow-list.
  • Any metric row lacks a quoted evidence string.
  • Any unverified row carries a value instead of a blank.
  • Any unverified row lacks a flag reference.
  • Any internal link points to a file that does not exist.
  • Any page lacks a title, or fails to load the stylesheet.
  • Any page contains a street address, coordinate pair, phone number, email address, SSN pattern, or card-number-like sequence.
  • Any page references a metric ID that does not exist in the dataset.
  • Any required page is missing.

The script is published in the repository at scripts/verify.mjs so the guarantee can be inspected rather than taken on trust.
