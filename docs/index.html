What this site is

An access-controlled public summary of official regional evidence plus a private calculator that runs only in the reader’s browser. Owner finances, lease PDFs, and identifiers stay offline.

  • Questions, known facts, and missing facts — start here before any commitment.
  • W-01 city and county proxies — labeled as proxies, not trade-area figures.
  • Same-store sales, unit counts, closures — system direction, not one quarter and not this store.
  • Private calculator — after-tax sale vs hold; inputs never uploaded.
  • Flagged for review — every blank or client-stated item.
  • Suggestions — review before implementing site or process changes.

Hard rules used on every page

  1. If a value was not read from an official source in this session, the cell is blank.
  2. City and county numbers are proxies until census tracts are selected privately.
  3. No sell/renew winner is published.
  4. Black-swan hazards are described with official maps; parcel status is blank.
