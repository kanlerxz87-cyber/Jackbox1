If personal data is discovered during research

It is for internal use only. It must not appear in commits, issues, pull requests, or this website. If it was pasted by mistake, delete it from git history before the next push and record the incident on the internal log — not on the public Flagged page.

This page is the publication boundary. When in doubt, omit.
