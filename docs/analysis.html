Analysis & Decision Framework

This page provides the sell-vs-renew/hold framework, after-tax comparison structure, risk register, and a printable executive summary. It intentionally contains no fabricated property economics. All property-specific values are blank until verified in a private, authorized workflow.

Decision rule (non-negotiable): Do not select a sell or renew winner until verified inputs exist for lease terms, current NOI/cash flow, tenant credit/sales, parcel hazards/insurance, tax basis and after-tax consequences, debt, market comps/quotes, and owner objectives/liquidity constraints. Any recommendation before that point is speculative and must be flagged.
