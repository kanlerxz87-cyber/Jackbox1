How to finish W-01 without publishing the site

  1. Geocode the withheld address offline.
  2. Select 2020 census tracts that match a pre-stated drive-time (for example 3-, 5-, 10-minute) and keep the list in the adviser vault.
  3. Pull ACS 5-year S0101, S1901, S1701, DP04 for those tracts from data.census.gov.
  4. Pull LODES / QCEW for jobs. Pull CDE DataQuest for schools. Pull LADOT counts for the intersection.
  5. Publish only blended, non-identifying totals if you publish at all.
PEP and ACS are different Census programs; they will not match exactly. Both are official. Neither is a trade area.
