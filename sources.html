Every figure on this site was read from one of the official domains below during the compilation session. This page states what each source was used for and, just as importantly, what it cannot be used for.

One rule governs every row. A value appears only if it was read from the linked official page. If the page did not load, the value is blank and the attempt is recorded on the Flagged for Review page. No figure on this site was taken from a secondary aggregator, a blog, a news article or a search-result snippet.

Verification method

  1. Locate the official page that carries the figure, preferring the agency's own domain over any index or mirror.
  2. Read the figure and the period and vintage labels from that page, not from a summary.
  3. Record the exact URL, the measure name, the geography and the period in data/*.json.
  4. Set verified: true only if step 2 succeeded. Otherwise leave the value null and write the reason.
  5. Rebuild the site. A null renders as a blank cell with a flagged badge; the row is listed on the Flagged page automatically.
  6. Re-read the figure when the source publishes a new vintage. The compile date is shown in the header of every page.

Reproducing this build

The site is generated, not written by hand. All content lives in data/ as JSON; the HTML is produced by tools/build_site.py. To re-verify one figure, edit the corresponding JSON entry, set its verified flag, change its source_url if needed, and rebuild. Changing the HTML directly will be overwritten by the next build, which is deliberate: it keeps the data and the presentation from drifting apart.

No runtime fetching. The published site makes no network requests at all. There is no external stylesheet, no font service, no script from a third party and no analytics. That means the pages cannot silently change after publication, and a reader can inspect exactly what was verified on the compile date.
