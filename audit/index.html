Overview

Independent verification dashboard

A source-linked, anonymous evidence layer for a single-tenant NNN property decision. It publishes only what can be confirmed from official primary sources, and leaves everything else blank and flagged.

Decision status: no transaction winner is defensible yet.

Every property-specific value is blank and flagged. The only decision supported by the information that currently exists is a verification-first, reversible hold: commit to neither a sale nor a renewal, keep collecting rent, and run both cases in parallel behind a hard private deadline. What this independent desk adds

  • Line-by-line provenance: every table row carries a link to the official primary source that was actually retrieved; see Official sources.
  • Blank means unverified: no value is inferred, interpolated or filled; see Flagged for review.
  • Aggregate-only evidence: verified regional economy, demographics, issuer series and tax rules are kept separate from parcel-specific unknowns; see Economy and Operator series.
  • Reproducible audit: verification/build.py regenerates every page from verification/data/dataset.json, and verification/check.py validates rows, links, privacy and JavaScript; see Repo review.
