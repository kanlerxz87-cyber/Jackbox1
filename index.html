What can be done this week, without spending anything

  1. Before 2026-11-30 — file the decline-in-value application. If the assessed value exceeds market value, the Los Angeles County Assessor's 2026-2027 window (opened 2026-07-02, closes 2026-11-30) cuts the property tax line — the largest fixed expense in a triple-net hold. Free, and the window closes in days. Source: LA County Assessor, Proposition 13 & decline-in-value programme.
  2. Pin the four lease dates. Option window opens, option deadline, tenant notice date, expiration. A lapsed renewal option is the only irreversible loss in this entire project. Nothing public can supply them — not even the tenant's SEC filings (see IR-02).
  3. Register a free Census API key. One key unlocks the tract-level trade-area pull that replaces city and county proxies. The query is prepared in data/tradearea.json and has never run because keyless requests are rejected. Source: Census API signup, api.census.gov/data/key_signup.html.
