# Property decision desk

Anonymous static research site for a commercial property decision. GitHub Pages serves `index.html` from the repository root. No build, package installation, external API, tracking, or backend is required. Open `index.html` locally or serve the root with a static web server.

The calculator is optional, uses only browser memory and does not calculate tax law. Do not put identifying information, private records, lease documents, or financial data in this public repository. A public static website is not an access-controlled workspace. See the Flagged for Review page for missing evidence and limitations.
