# Anonymous Central LA NNN workspace

Public GitHub Pages site for an **anonymized** sell-versus-renew review of a Jack in the Box NNN lease described as located around Central Los Angeles.

**This repository must not contain** owner names, street addresses, APNs, lease PDFs, tax returns, or unit-level sales.

## Live site

After GitHub Pages is enabled on the `docs/` folder of `main`:

`https://kanlerxz87-cyber.github.io/Jackbox1/`

## What is published

- City and county **proxies** from the U.S. Census Bureau and California EDD (W-01 still open).
- Brand-level same-store sales and unit counts from the issuer’s FY 2025 earnings release.
- Regional USGS earthquake probabilities; parcel flood/fire/seismic **blank**.
- Verified IRS / FTB / BOE tax **rules**.
- An in-browser calculator (no server).
- Decision gates, questions, suggestions, and a Flagged for Review page.

**No sell or renew recommendation is made.**
