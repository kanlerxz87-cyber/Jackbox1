## Conventions adopted by this session (so later sessions don't fight the data)

1. **No personal data, ever.** No parcel address, APN, owner name, tenant-identifying
   detail, lease terms or financial figures of the owner appear on the site. The site is
   public; the workspace for private material is *offline*. Identifiers appear only as
   placeholders (`PARCEL-A`, `OWNER-1`, `TENANT-A`, `ADVISER-1`).
2. **One source of truth**: every table row lives in `data/*.json` with
   `value`, `unit`, `period`, `source_url`, `source_name`, `verified` and `note`.
   HTML is generated by `tools/build_site.py`; do not hand-edit generated HTML.
3. `verified` is only `true` when this session fetched the value from the linked official
   page. Unconfirmed values are **left blank** (`value: null`) and carry
   `verified: false` + a reason; they surface on `/flagged.html`.
4. Nothing is inferred, interpolated or "reasonable assumed" into a value field.
   Assumptions live in `data/assumptions.json` and are labelled as assumptions in the UI.
