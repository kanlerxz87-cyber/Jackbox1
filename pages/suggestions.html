Suggestions

A dedicated review section. Each suggestion is a proposal with a stated benefit, cost, risk of adopting it, and a status. The owner reviews and chooses the path BEFORE anything is implemented. Nothing on this page has been auto-applied.

How to use this pageRead the suggested path first, then the individual proposals. Each proposal carries a 'decision needed from you' line so a choice can be recorded. Statuses are: proposed, under review, rejected, adopted. None are adopted.

Suggested path

Path A — Close the cheap gaps first, then decide

Two of the fifteen gaps cost nothing and take days: the Census API key (G-02) and the decline-in-value filing whose window closes 2026-11-30. A third, the lease date (G-04), is already in the owner's filing cabinet. Those three move the project further than any additional research, because they turn an eight-year uncertainty into a date and turn city averages into tract figures.

  1. Register a Census API key and re-run the documented tract query. (free, under an hour of work)
  2. Pull the executed lease and write down four dates: option window opens, option deadline, tenant notice date, expiration. (free)
  3. If assessed value exceeds market value, file the decline-in-value application before 2026-11-30. (free, dated)
  4. Read the insurance binder and record premium, limits, deductibles, BI period and renewal date. (free)
  5. Only then engage brokers for cap-rate opinions and order a property condition and seismic assessment. (paid, but now scoped to the right asset and term)

Why not the alternative: Path B (start with brokers and diligence) spends money before the term is even known. Pricing a 3-year asset and a 9-year asset are different exercises; doing the expensive work first risks having to redo it.

Decision needed from youApprove Path A, or choose Path B, or write your own order on the Flagged for Review page.

SG-04 · analysis

Treat the metro back-test result — strong mean reversion in 5-year appreciation — as the reason to model zero real appreciation by default.

proposed
Benefit

Prevents the most common error in this asset class: underwriting the last five years' growth forever.

Cost

Nothing

Risk of adopting

If the regime has genuinely changed, the default is too conservative. The calculator lets the reader override it.

Decision needed from you: Accept zero real appreciation as the default, or set your own growth assumption.

SG-06 · process

proposed

Review workflow

  1. Owner reads Path A through D and marks one as chosen (or writes a custom order).
  2. Owner goes through SG-01 to SG-12 and sets each to under review, rejected or adopted.
  3. Only adopted items get implemented, in a separate commit, with the decision recorded in COORDINATION.md.
  4. Anything still unverified stays on the Flagged for Review page regardless of adoption.

Privacy. This site publishes aggregate, non-identifying findings only. No parcel address, owner identity, APN, lease document, rent figure or personal finance appears anywhere in this repository or on this site. The parcel is referred to as PARCEL-001 throughout.

Integrity. Every data row carries a source identifier linking to an official source. Where an official source could not confirm a value, the value is left blank and listed on Flagged for review. Nothing is inferred or filled in.
