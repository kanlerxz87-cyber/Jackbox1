Overview

A clean, category-organized dashboard for one single-tenant NNN quick-service property around central Los Angeles. The lease expiry is known only as a range (2030–2035). No sell/hold winner is selected because verified private inputs do not exist. Every published table row links an official source; unconfirmed values are blank and flagged.

Decision status

No winner selected — evidence gates are open

The only defensible current course is a gated, privacy-first process: protect identity, fix the tract set, abstract the lease and notice calendar, verify parcel hazards and market quotes, then compare an after-tax sale with a negotiated renewal. This is a process recommendation, not a property-value conclusion.
