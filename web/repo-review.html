Verification performed

  1. Source check: every table row resolves to an official source id; every source URL is HTTPS and on a recognised official host (or the repository itself for repo-review rows).
  2. Value check: a row marked verified must have a non-blank value; a row not marked verified must have a blank value. No inferred values.
  3. Privacy scan: published files are scanned for identifiers, street-address patterns, APN patterns and owner-financial keywords.
  4. Link check: all internal href/src targets must exist; external links are opened in a new tab with rel="noopener noreferrer".
  5. Build check: the static site is generated locally, then served over HTTP and checked for 200 responses.

Method limits

Only pages retrieved and read in this session are used for published values. Search snippets, unofficial summaries and portal pages that were not fetched are never used as data. BLS/EDD preliminary values and mixed Census vintages are flagged. SCAG forecasts are labelled projections. No parcel-specific value is inferred from a regional figure.
